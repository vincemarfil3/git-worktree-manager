Worktree paths & branch format

Where the native host finds stories.json, where per-story worktrees and the generated .code-workspace files are created, and how a new story's branch name is derived. Leave a field blank to use the default shown as its placeholder — an existing story keeps whatever root it was actually created under even if you change this later.

Organization settings

Links, GitHub-Actions matching, and the folder-name → repo-name alias — all org-specific, none hardcoded. Blank = the built-in default shown as the placeholder.

Apps

A repo cloned at your story root shows up below automatically. Add a port, start command and health path so the ⚡ ports/health button and story-env.ps1 can manage it — without one it just shows "unmapped". You can also map an app that isn't cloned yet, or hide one you never want offered in the + New story checklist (it stays listed here, unhide any time). Saved to %LOCALAPPDATA%\story-tab-groups\app-map.json, separate from the tools\ copy this ships with.
